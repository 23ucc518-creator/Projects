| [Mutual-Similarity-Graph-Learning-with-Density-Regualarization-for-Robust-Financial-Fraud-Detection](https://github.com/23ucc518-creator/Mutual-Similarity-Graph-Learning-with-Density-Regualarization-for-Robust-Financial-Fraud-Detection) | Dec 2025 | Python, PyTorch, Data Preprocessing, Pandas, Deep Learning, GCN | Built a unified Graph Neural Network framework for financial fraud detection that works across two very different datasets — credit-card transactions and PaySim mobile money transfers — by converting both into graph structures (k-NN similarity graphs for transactions, account-interaction graphs for PaySim) and training a Graph Convolution Network (GCN) on each. Applied standardization, PCA-based dimensionality reduction, and both 70/30 split and 7-fold cross-validation for robust evaluation. Achieved strong results (F1-score of 0.9977 on PaySim, 0.9991 on credit-card data), outperforming several existing published approaches on the same datasets. |

Performed EDA to uncover key survival patterns, then built a Logistic Regression model on the processed data. Achieved ~83% prediction accuracy, with sex and passenger class emerging as the strongest survival predictors.|
